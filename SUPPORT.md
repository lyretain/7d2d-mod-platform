# Hordepin Support

Hordepin is a community-maintained project provided without guaranteed response or resolution times.

## Where to ask

- Read [README.md](README.md), [README.zh.md](README.zh.md), and the [documentation index](docs/README.md) first.
- Use a GitHub bug report for reproducible defects.
- Use a feature request for proposed improvements.
- Use GitHub Discussions for setup questions and community help when Discussions are enabled. If Discussions are unavailable, open a clearly labeled question Issue.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose them publicly.

Include the platform version, plugin version, game version, Steam Build, operating system, deployment mode, minimal reproduction, expected behavior, and redacted logs. Remove tokens, passwords, player identifiers, home-directory paths, public IP addresses, private Mod files, and proprietary game files.

Installation-specific commercial support, hosting, and third-party Mod compatibility are outside the guaranteed scope of this repository.
